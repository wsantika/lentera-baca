## Summary

Mengganti ketergantungan pada Web Speech API dengan arsitektur audio player baru yang memprioritaskan file audio statis terkurasi Bahasa Indonesia. Jika file audio belum tersedia, otomatis fallback ke Speech API (`id-ID`). Menyiapkan struktur folder aset audio dan panduan rekaman.

## Changes

### Audio Infrastructure
- **`src/config/audio.ts`**: Konfigurasi pemetaan path audio. Konvensi penamaan: `/audio/letters/{huruf}.mp3`, `/audio/reading/{exercise_id}.mp3`, `/audio/sfx/{nama}.mp3`.
- **`src/lib/hooks/use-audio-player.ts`**: Custom hook pengganti `useSpeech`. Mencoba load file `.mp3` terlebih dahulu via `HTMLAudioElement`, jika gagal (404/error) otomatis fallback ke `speechSynthesis`. Expose `speak(audioPath, fallbackText)`, `speakText(text)`, `cancel()`, dan `isSpeaking`.

### Consumer Updates
- **`src/components/letters/letter-lesson.tsx`**: Migrasi dari `useSpeech` → `useAudioPlayer`. `handleSpeak` sekarang memanggil `speak(getLetterAudioPath(letter), speechText)`.
- **`src/components/reading/reading-practice.tsx`**: Migrasi dari `useSpeech` → `useAudioPlayer`. `handleListen` sekarang memanggil `speak(getReadingAudioPath(id), speechText)`.

### Audio Asset Pipeline
- **`public/audio/`**: Struktur folder siap pakai untuk aset audio terkurasi.
  - `letters/` — File pengucapan huruf A-Z (`.mp3`)
  - `reading/` — File audio latihan membaca
  - `sfx/` — Sound effects (correct, incorrect, complete)
- **`public/audio/README.md`**: Panduan rekaman audio (format, bitrate, panduan konten, penamaan file).

### Backward Compatibility
- **`src/lib/hooks/use-speech.ts`**: File lama tetap dipertahankan (tidak dihapus) untuk kompatibilitas jika ada komponen lain yang masih menggunakannya.
